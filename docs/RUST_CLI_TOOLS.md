# Top 10: Rust CLI Tools

> **Källa:** [rust-unofficial/awesome-rust](https://github.com/rust-unofficial/awesome-rust)
> **Urval:** Mest användbara CLI-verktyg för developers och sysadmins

---

## TOP 10

| # | Namn | Ersätter | Beskrivning | Install |
|---|------|----------|-------------|--------|
| 1 | ripgrep | grep | Blixtsnabb regex-sökning — respekterar .gitignore | `cargo install ripgrep` |
| 2 | fd | find | Enkel och snabb filsökning med intuitivt syntax | `cargo install fd-find` |
| 3 | bat | cat | Filvisning med syntaxmarkering och Git-integration | `cargo install bat` |
| 4 | eza | ls | Modern ls med färger, ikoner och trädvy | `cargo install eza` |
| 5 | zoxide | cd | Smart katalognavigering som lär sig vanor | `cargo install zoxide` |
| 6 | tokei | wc -l | Räknar kodrader per språk | `cargo install tokei` |
| 7 | cargo-audit | — | Skannar Rust-dependencies för CVEs | `cargo install cargo-audit` |
| 8 | gitui | git TUI | Blixtsnabb terminal-UI för Git | `cargo install gitui` |
| 9 | bottom | htop | Plattformsoberoende systemmonitor | `cargo install bottom` |
| 10 | dust | du | Intuitiv diskutrymmesanalys | `cargo install du-dust` |

---

## Snabbinstallation

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
cargo install ripgrep fd-find bat eza zoxide tokei cargo-audit gitui bottom du-dust
```
